# NBTI 网络角色文案与展示层说明

## 目的

NBTI 的网络角色只用于帮助用户记住本组情境中反复出现的处理动作，不是人格类型、心理诊断、能力评级或道德判断。底层 `nbti-mvp` v1 仍使用四个双向维度和原有稳定结果 ID；角色是独立的展示层。

## 初期素材

首批已生成并接入六个角色：

- 看门狗 `watchdog`
- 杠精 `stress-tester`
- 赛博判官 `cyber-adjudicator`
- 卷王 `iteration-engine`
- 头铁 `fixed-bearing`
- 人间清醒 `signal-clarifier`

原始文件位于 `references/generated-assets/`。实现过程只读取文件名和文件信息，不检查图片内容。发布副本转换为 WebP，位于 `public/assets/report-roles/`。其余角色的 `assetSrc` 保持为空，报告页显示有意留白，不请求不存在的图片。

## 文案原则

统一句式：`在这组复杂情境里，你更常先……`。

- 不写“你就是”“你天生”“说明你更聪明”。
- 不把贬义称号洗成能力勋章。
- 每个高歧义称号在角色正文中单独消歧。
- 题目只描述可观察动作，不直接出现结果称号或暗示正确答案。
- 保留统一声明：换一组现场，结果可能不同。

## 六个称号的语义边界

### 看门狗

借用“守住信息入口”的动作，具体写核对来源、条件、口径和异常点。中文语境中也可能指依附权势者，因此正文明确不表示多疑、监视或攻击他人。

来源：[汉典：看门狗](https://www.zdic.net/hans/看门狗)、[百度百科：看门狗](https://baike.baidu.com/item/看门狗)

### 杠精

通行含义明显偏贬义，通常指为了反对而反对。本产品只借用“用反例和边界条件给说法做压力测试”的动作，并要求角色动作最后回到补全论证。

来源：[百度百科：杠精](https://baike.baidu.com/item/杠精/22163222)、[维基百科：抬杠](https://zh.wikipedia.org/wiki/抬杠)

### 赛博判官

借用平台大众评审、在线处理争议的意象，表达把材料放到同一标准下比较。正文明确不表示拥有审判他人的权力，也不鼓励草率网络审判。

来源：[百度百科：赛博判官](https://baike.baidu.com/item/赛博判官)；中国青年网 2023-12-22《今日漫话｜“赛博判官”兴起，秉持正义才能解决争议》。

### 卷王

来自“内卷”语境，通常指以超常投入拉高竞争强度的人，褒贬混合。本产品只描述追加动作、提高反馈频率和连续修订的推进节奏，不赞美过劳，不表示优于他人。

来源：[百度百科：卷王](https://baike.baidu.com/item/卷王)、[维基百科：内卷化](https://zh.wikipedia.org/wiki/内卷化)

### 头铁

常指固执、倔强或不懂变通，也可能在特定语境中赞扬坚持。本产品限定为短期阻力出现时先维持方向，并要求设置复盘节点；不表示拒绝新证据或一意孤行。

来源：[百度百科：头铁](https://baike.baidu.com/item/头铁)

### 人间清醒

通常是褒义表达，容易滑向“比别人理性、看得更透”的能力暗示。本产品只描述先分开事实、气氛、期待和现实限制，正文明确不表示总能看透真相。

来源：[百度百科：人间清醒](https://baike.baidu.com/item/人间清醒/56276532)

## 其余角色

破壁人、绝活哥、思想钢印、树人、赌神和扫地僧已建立展示元数据。树人是产品自定义隐喻，正文明确说明其含义。

破壁人、思想钢印和扫地僧具有明确文学或影视作品联想，正式商业化前应进行命名和知识产权复核。

## 技术边界

- URL 继续只编码系列、版本和 12 个答案索引。
- 原有 `primaryResultId` 和 JSON `resultTypes` 不变。
- 展示角色由稳定结果 ID 与一个次级维度共同决定。
- 弱信号仍显示“多路者”，不会被包装成强角色。
- 修改题目文字后已更新问卷 `contentDigest` 为 `sha256:cab42a7aa8b5d96ac65c9448c111fe28f8433d32d8a281fc3911908210f187d7`，题目 ID、选项 ID、顺序和权重保持不变。
