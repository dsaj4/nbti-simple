# 报告页设计简报

视觉参考位于 `references/report-design/`。

## 页面层级

1. 结果身份：结果名、编码、短副标题、分享动作。
2. 主舞台：一个能把思维动作可视化的场景或角色瞬间。
3. 解释：维度、稀有度、短解释与相关状态。
4. 边界：非诊断、非授权背书提示。

## Editorial Stage 主方向

- 编辑排版与小型剧场感。
- 暖白或象牙白底，深色文字，成熟红色强调，少量青绿色数据表达。
- 桌面端可采用主舞台与解释面板的并置；移动端优先结果、舞台、解释的纵向阅读。
- 不使用 HUD、赛博朋克控制台或密集 dashboard。

## Paper Puppet 备选

- 纸偶、票根、纸纹和舞台剪影。
- 更适合手作感、轻传播和对 cameo 的非写实表达。
- 不儿童化、不做脏旧感、不用黑暗审判场景。

这些是设计意图，不是旧 CSS、像素和组件的复刻任务。
