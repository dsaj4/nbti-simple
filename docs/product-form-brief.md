# NBTI 产品形态简版

## 这份文档回答什么

这份文档只回答一个问题：

> **用户打开 NBTI 后，具体会体验什么？**

旧形态是“趣味测试”：完成一组题目，计算类型，查看并分享人格报告。它简单清楚，但趣味性和类型差异很难长期超过成熟竞品，也不能自然体现“方法发现入口”的新定位。

## 版本一：升级版趣味测试

**形式：** 保留完整测试流程，但把抽象自评题改为场景选择，把结果从固定人格改为“思维动作角色”。

```text
完成题组 → 获得角色 → 查看维度与解释 → 分享
```

**优势：**

- 最容易承接现有网站和报告页；
- 用户无须学习新玩法；
- 研发和内容成本最低。

**问题：**

- 本质仍然是一次性测试；
- 方法只出现在报告文案中，用户没有真正用过；
- 需要不断增加类型和系列维持新鲜感。

**适合：** 作为近期过渡版本，不适合作为长期主形态。

## 版本二：单场景思维挑战

**形式：** 每次只进入一个有冲突的短场景。用户先选择，再看到自己刚才使用的判断方式，最后获得一张可分享的结果卡。

```text
一个场景 → 一次选择 → 一次解释 → 一张分享卡
```

**优势：**

- 比完整测试更轻，适合热点、社交传播和持续更新；
- 每个场景都能独立访问和分享；
- 可以快速测试哪些主题最有吸引力。

**问题：**

- 如果只做选择和解释，仍然只是“更短的测试”；
- 单个样本不足以形成可靠的角色总结；
- 容易滑向投票站或观点站队。

**适合：** 作为内容原子和传播入口。

## 版本三：思维共演场

**形式：** 用户先在场景中作出自然选择，再由一种方法或一位方法型角色提出关键问题，用户可以坚持、修正、改选或暂不判断。

```text
场景初选
  → 说明主要理由
  → 与一种方法共演
  → 再次判断
  → 获得前后变化与方法总结
```

**优势：**

- 用户真正体验了方法，而不只是阅读结果；
- 名人共演可以转化为“名人方法”，而不是人格模仿；
- 与 Hub 的连接最自然：把刚用过的方法带到真实问题；
- 坚持和改变都能形成有价值的结果。

**问题：**

- 场景、理由和方法之间需要认真匹配；
- 交互比普通测试多一步，必须保持足够轻；
- 方法如果写得太重，会变成教学或说教。

**适合：** 作为推荐的核心玩法。

## 版本四：多幕思维旅行

**形式：** NBTI 不再是一组测试题，而是一段类似 RPG 结构的多幕选择旅程。用户带着一个初始身份出发，在不同地点和事件中作出选择，途中遇见不同名人或原创角色，从他们代表的方法中获得“旅途收获”。此前的选择和收获会影响后续路线，最后抵达一个属于自己的结局。

```text
出发
  → 多幕场景与选择
  → 遇见方法型人物
  → 获得并使用旅途收获
  → 路线发生变化
  → 抵达个人结局
```

**优势：**

- 从根本上摆脱“答题—计分—拿类型”的测试感；
- 名人共演、场景抉择和方法获得被统一进同一段旅程；
- 选择会产生后续影响，趣味性、代入感和完成动力更强；
- 最终结局来自整段路径，比固定人格类型更有个人性；
- 用户获得的方法可以在后续幕继续使用，也能自然带入 Hub。

**问题：**

- 编剧、美术、分支和状态管理成本明显提高；
- 如果分支过多，内容量会迅速失控；
- 如果人物只负责彩蛋，用户会只记住名人而忘记方法；
- 如果结局只是隐藏评分映射，仍然是披着旅行外衣的测试。

**适合：** 作为推荐的完整产品外壳，但首版应采用有限分支和可汇合路线，而不是制作大型 RPG。

## 版本五：思维体验平台

**形式：** NBTI 成为一个持续更新的体验集合，包含场景挑战、名人方法、双人对局、多幕旅程和创作者系列。

```text
内容首页
  → 选择不同主题和玩法
  → 累积个人判断轨迹
  → 分享、对比或进入 Hub
```

**优势：**

- 能形成长期内容产品，而不是单次测试；
- 可以容纳不同人群、主题和合作内容；
- 有机会建立社交传播和持续使用。

**问题：**

- 需要账户、内容运营、审核和推荐等完整平台能力；
- 很容易与 Hub、Lab 再次形成平级产品线；
- 当前没有证明核心玩法成立，过早建设风险最大。

**适合：** 作为长期可能，不作为近期建设目标。

## 推荐形态

建议采用“一个核心玩法 + 一个完整外壳”：

> **核心玩法：思维共演场。**

每次体验以一个短场景为单位，用户先自然选择，再亲自使用一种方法完成再判断。这是 NBTI 相比普通测试最重要的差异。

> **完整外壳：多幕思维旅行。**

用户不是连续做题，而是在一段有起点、相遇、分路和终点的旅程中完成多次思维共演。每位名人或原创角色代表一种可使用的方法；用户沿途获得的不是装备和战力，而是新的追问、判断工具和看问题的视角。

组合后的用户路径是：

```text
以一个待回答的问题出发
  → 在第一幕作出自然选择
  → 旅途中遇见不同方法型人物
  → 通过共演获得方法收获
  → 在后续幕主动使用、拒绝或改造这些方法
  → 选择逐渐改变自己的路线
  → 抵达一个由路径、理由和收获共同形成的个人结局
  → 将最有用的方法带入 Hub 的真实问题
```

单场景挑战仍可作为公开分享和朋友邀请的轻入口，现有舞台式报告则可以承担终幕结局页。但它们都服务于完整旅程，而不是各自成为一套产品。

### RPG 类比的边界

RPG 只用来类比“扮演、旅行、相遇、选择、获得和结局”的体验结构。NBTI 当前不需要：

- 战斗系统；
- 等级与战力；
- 装备稀有度；
- 开放世界；
- 大量支线任务；
- 复杂资源经营。

NBTI 真正的成长，是用户获得一种方法，并在后续选择中知道何时使用、何时拒绝。

## 近期最小版本

第一版不需要做“平台”，只需要证明核心玩法成立：

- 一段有明确出发问题的短旅程；
- 三至四幕主要场景；
- 两至三位方法型名人或原创角色；
- 两次有限分路，随后允许汇合，控制内容规模；
- 每幕包含选择、理由、人物共演和方法收获；
- 至少一次让用户在后续幕主动使用此前收获；
- 三至五个有明显差异、但没有高低等级的个人结局；
- 一份以现有舞台视觉呈现的终幕结局页；
- 一个把当前方法带入 Hub 的入口。

暂不优先建设完整类型宇宙、开放创作、战斗养成、复杂分支树、连续长篇剧情和独立账户体系。

## 团队校准句

以后判断一个具体玩法是否符合推荐形态，可以先问：

> 用户是在连续答题，还是在一段会因选择和方法收获而改变的旅程中前进？

只有后者才构成“多幕思维旅行”；如果拿掉旅行包装后仍是一套计分题，它就没有真正完成改造。
